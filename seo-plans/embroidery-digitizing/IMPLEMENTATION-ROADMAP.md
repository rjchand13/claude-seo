# Implementation Roadmap

## Phase 1: Foundation (weeks 1–4)

- [ ] Choose a brandable domain (check its history before buying an aged one)
- [ ] Build the site: fast theme, HTTPS, mobile-first, upload and quote form
- [ ] Order flow: artwork upload, size and placement, format, rush option, payment
- [ ] Launch pages: Home, Embroidery digitizing, Logo, Cap, Pricing, Portfolio, About, Guarantee, FAQ, Contact, Legal
- [ ] Schema: Organization, WebSite, Service with offers, Article
- [ ] Google Search Console, Bing Webmaster Tools, GA4 with conversion events (quote submitted, order paid)
- [ ] robots.txt, XML sitemap, `llms.txt`
- [ ] Google Business Profile (service-area business, no public address needed) and a Trustpilot profile
- [ ] Portfolio: at least 20 before/after pieces with sew-out photos

**Exit check:** all pages indexed, Core Web Vitals passing, test order completed end to end.

## Phase 2: Expansion (weeks 5–12)

- [ ] Publish month 2–3 calendar items (service pages, format pillar, cost guide)
- [ ] First-design-free offer for new customers to collect reviews fast
- [ ] Review request email after every order
- [ ] Internal linking pass across all pages
- [ ] First 10–20 links: supplier directories, embroidery communities, guest guides
- [ ] YouTube channel: short stitch-out videos, embedded on service pages

**Exit check:** first long-tail rankings in the top 10, first organic orders.

## Phase 3: Scale (weeks 13–24)

- [ ] Months 4–6 content: re-digitizing, conversion pages, machine pages, tools
- [ ] Launch the price calculator and the machine format finder (outreach to embroidery blogs)
- [ ] White-label outreach to embroidery shops (B2B repeat accounts)
- [ ] Check AI answer visibility (ChatGPT, Perplexity, Google AI Overviews) for "best embroidery digitizing service" and improve quotable facts
- [ ] Performance tuning; compress portfolio images
- [ ] Run `/seo audit` on the live site

**Exit check:** 50+ quote requests a month from organic search.

## Phase 4: Authority (months 7–12)

- [ ] Original research piece (test-stitch study) and PR outreach
- [ ] Annual price report
- [ ] Case studies every month
- [ ] Quarterly refresh of pricing and top 10 pages
- [ ] Target the head term "embroidery digitizing service" with a strengthened main page
- [ ] Set up `/seo drift` monitoring on key pages

**Exit check:** 100+ organic orders a month, 80+ referring domains.

## Resources needed

| Need | Minimum |
|---|---|
| Digitizer(s) | One skilled digitizer (Wilcom or Pulse) plus a test machine for sew-outs |
| Content | About 20 hours a month writing or editing |
| Photos and video | Phone + light box; stitch-out clips |
| Tools | Search Console, GA4, a keyword tool, optionally Ahrefs, Moz or DataForSEO |
| Budget | Domain and hosting; first-design-free offers as the main marketing cost |

## Dependencies

- Sew-out photos depend on access to an embroidery machine. This is the core differentiator, so plan for it before launch.
- Reviews depend on real orders, so the first-design-free offer should start in Phase 2.
